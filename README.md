# صَرْفة — Sarfa

تطبيق أندرويد أصلي، أبيض وبسيط، لتسجيل المصروفات والدخل بالصوت مع مراجعة المبلغ وتأكيد واحد قبل الحفظ. لا يستخدم Floot ولا خدمات ذكاء اصطناعي مدفوعة.

## الميزات
- زر صرف بالصوت وزر دخل بالصوت باستخدام خدمة التعرف على الكلام في هاتف أندرويد باللغة العربية السعودية.
- يفهم أمثلة مثل: «15 ريال عشاء لحمودي»، «دخل 500 ريال راتب»، «صرفت ٣٠ ريال بنزين»، «خمسة عشر ريال قهوة».
- يفهم الأرقام العربية والهندية والكسور النقدية الرقمية، ويرفض المبلغ المفقود أو المبالغ الرقمية المتعددة.
- يعرض مبلغ العملية ونوعها وتصنيفها ووصفها في نافذة تأكيد. الإلغاء أو إعادة التسجيل لا يغيران الرصيد.
- الرصيد المتاح = مجموع الدخل المسجل ناقص مجموع الصرف المسجل. لا يوجد اتصال بحساب مصرفي.
- ملخص دخل وصرف الشهر، وسجل العمليات مع تأكيد عند الحذف.
- تصدير تقرير PDF عربي يحوي الرصيد والإجماليات والعمليات، مع تقسيم تلقائي إلى صفحات عديدة.
- يحفظ العمليات محليًا على الجهاز في SharedPreferences. لا يتطلب حسابًا أو خادمًا.
- واجهة بيضاء بالكامل مع تفاصيل خضراء هادئة.

## الاختبار والبناء على GitHub
اذهب إلى تبويب Actions واختر أحدث تنفيذ من Build and test Android APK. يجرّب:
1. اختبارات Java لمنطق المبلغ العربي والحسابات.
2. بناء APK حقيقي.
3. اختبارات أندرويد على محاكي: تأكيد/حفظ/إلغاء/دخل/صرف/حذف.
4. إنشاء ملف PDF عربي حقيقي وفتحه باستخدام PdfRenderer وفحص أنه قابل للرسم، واختبار التقسيم لصفحات.
5. يحفظ ملف APK وملفات PDF التجريبية في Artifacts لتنزيلها من الجوال.

مهم: يعتمد التسجيل الصوتي على توفر خدمة تعرف على الكلام باللغة العربية على الهاتف وقد يتطلب إنترنت بحسب المحرك. صوت المستخدم يعالجه تطبيق التعرف على الكلام الذي يختاره أندرويد؛ التطبيق لا يرفع سجلات المصروفات إلى خادم خاص به.

## ملاحظات
- التحقق من رقم المبلغ قبل الضغط على «تأكيد وحفظ» ضروري، لأن المحرك الصوتي قد يسمع بعض الكلمات بطريقة خاطئة.
- التطبيق يسجل مصروفًا محاسبيًا فقط، ولا يسحب أموالًا فعليًا من البنك.
- عند حذف بيانات التطبيق من إعدادات النظام تُحذف البيانات المحلية؛ احتفظ بتقارير PDF المهمة خارجيًا.
- نسخة أولية؛ لا تدّعي أنها اختُبرت على جميع موديلات الهواتف أو أنها تدعم كل صياغات الأعداد العامية.

## المتطلبات
Android 8.0+؛ للتطوير Gradle 8.11.1 وAndroid Gradle Plugin 8.9.2 وJDK17 وSDK35. كود Java أصلي دون مكتبات UI مدفوعة.
